# news-image-20261120

make.fun bounty entry: one image summing up the world news of
Friday, 20 November 2026.

- `entry.png` — the image (1024×1024, PNG), drawn from code.
- `main.py` — the entry program: copies `entry.png` to `/output/entry.png`.
- `build_image.py` — the script that drew the image (Pillow + DejaVu Sans).

Stories covered: the ICJ's genocide ruling against Myanmar, the first
Trump–Xi–Putin summit in Shenzhen, Russian strikes on Kyiv, the global
market sell-off and Anthropic's Nasdaq debut, the Houthi missile strike
on Riyadh, and GTA 6's $2.3 billion launch.
